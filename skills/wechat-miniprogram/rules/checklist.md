# 小程序渗透检查清单

> 逐项勾选；未做的项写明原因（不适用/超出授权/环境限制），别静默跳过。

## 0. 授权与准备

- [ ] 明确主体、授权范围（域名/接口/云环境）、禁止项
- [ ] 准备测试账号 A（普通用户）、B（另一个普通用户）、管理员（如授权）
- [ ] 测试机装好 MITM CA 证书，代理联通（`http_request` 能留痕）
- [ ] 建任务目录，证据统一落 `save_evidence`

## 1. 取包

- [ ] Android：`scripts/collect_android.sh` 或 adb 手动 pull
- [ ] PC：`scripts/collect_windows.ps1` 或 `WeChat Files/Applet`
- [ ] 记录包哈希、版本、获取时间，`save_evidence`

## 2. 解包与静态审计

- [ ] `miniprogram_unpack` 解包成功（失败记录变体类型并改用外部工具）
- [ ] `miniprogram_audit` 产出接口/密钥/云环境/云函数/appid/sourcemap
- [ ] 有 sourcemap 则还原源码，扩大接口与密钥发现
- [ ] 将新发现的域名/接口 `insert_assets`

## 3. 抓包与接口盘点

- [ ] 跑核心链路：登录、首页、列表、详情、下单/支付、个人中心
- [ ] 导出真实请求，与静态清单比对，补全遗漏接口
- [ ] 标注每个接口：认证方式、角色、参数、返回敏感字段

## 4. 登录态与身份矩阵

- [ ] A 身份登录态入 cookie jar（`session_login`）
- [ ] B 身份登录态（另一个 jar / `auth_request` 凭据组）
- [ ] 未登录态
- [ ] 记录 openid/unionid/userId/token 的来源与可替换性

## 5. 接口测试（按优先级）

- [ ] 未授权（6）
- [ ] 水平越权（7）/ 纵向越权（8）/ IDOR（9）
- [ ] JWT/Token 缺陷（10）/ 登录态伪造（11）
- [ ] 支付金额篡改（14）/ 回调伪造（15）/ 订单越权（16）
- [ ] 注入：SQL/NoSQL/命令/模板/XXE（20–24）
- [ ] SSRF（25）/ 上传（26）/ 穿越（27）
- [ ] XSS/CSRF/CORS/明文传输/弱加密（28–33）
- [ ] 验证码/短信（12）只做少量验证

## 6. 云开发专项

- [ ] 云函数未授权调用（34）
- [ ] 云函数越权（35）
- [ ] 云数据库未授权读写（36，只读少量）
- [ ] 云存储未授权/遍历（37）
- [ ] 环境隔离（38）

## 7. 开放能力专项

- [ ] code2session 滥用（39）
- [ ] 手机号解密接口滥用（40）
- [ ] 订阅/模板消息注入（41）
- [ ] 支付 V3 回调/证书（42）
- [ ] GraphQL/调试接口/限流（43）

## 8. 证据与报告

- [ ] 每条漏洞有可复现请求/命令 + 关键输出 + 流量 ID
- [ ] 越权类有 A/B 双身份对照
- [ ] `report_finding` 已登记，critical/high 通过 evidence 复核
- [ ] 按 `report-format.md` 出专项章节
- [ ] 否定结论已写 `record_fact`
